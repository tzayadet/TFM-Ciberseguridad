# TFM Ciberseguridad

Repositorio de referencia para el Trabajo de Fin de Máster en Ciberseguridad. Recoge herramientas y recursos utilizados durante la preparación del entorno de laboratorio y las actividades de análisis.

## Herramientas documentadas

- Ubuntu Desktop y Ubuntu Server.
- Lynis para auditoría de seguridad en sistemas Linux.
- OpenVAS / Greenbone para análisis de vulnerabilidades.
- VirtualBox para crear entornos virtualizados y aislados.

## Documentación

- [Ubuntu](https://ubuntu.com/tutorials)
- [Lynis](https://cisofy.com/lynis/)
- [Greenbone](https://greenbone.github.io/docs/)
- [VirtualBox](https://www.virtualbox.org/manual/)

## Consideraciones

Las versiones y enlaces de descarga pueden cambiar. Consulta siempre las páginas oficiales antes de instalar herramientas. Ejecuta escaneos únicamente sobre sistemas propios o con autorización expresa.

## Alcance

Repositorio de apoyo académico y documentación. No sustituye la memoria completa del TFM ni acredita por sí solo la ejecución de todas las herramientas.
